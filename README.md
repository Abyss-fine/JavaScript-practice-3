# Практическая работа № 3 — Работа с DOM и событиями

## Цель работы

Изучить работу с DOM, обработку событий и динамическое обновление интерфейса средствами JavaScript.

## Описание проекта

Веб-приложение для отображения и управления списком задач.

Реализованы:
- отображение карточек задач;
- отображение статуса и приоритета задачи;
- переключение статуса выполнения;
- удаление задач;
- фильтрация по всем задачам, выполненным и невыполненным;
- отображение статистики: всего, выполнено, осталось, прогресс и количество показанных задач;
- отображение сообщения, если список пуст или фильтр не находит задачи;
- два набора данных: демонстрационный и собственный вариант.

## Структура проекта

- `index.html` — основная страница приложения;
- `styles.css` — оформление интерфейса;
- `src/data.js` — наборы данных;
- `src/task-service.js` — операции с задачами и статистика;
- `src/task-selectors.js` — фильтрация задач;
- `src/task-view.js` — создание карточек и обновление интерфейса;
- `src/main.js` — обработка событий и управление приложением;
- `examples/` — пример работы с DOM-событиями;
- `checks/` — сервисные проверки;
- `checks.html` — инструкция по ручной проверке;
- `tools/serve.mjs` — локальный HTTP-сервер.

## Запуск

Требуется установленный Node.js.

Из папки `practice-03` выполнить:

```powershell
npm start
```

Открыть в браузере:

http://127.0.0.1:5503/

Для собственного варианта использовать ссылку «Свой вариант» в приложении.

## Проверка

Запустить сервисные тесты командой:

```powershell
npm run check:service
```

Или напрямую:

```powershell
node checks/service.checks.js
```

Также доступна страница ручной проверки:

http://127.0.0.1:5503/checks.html

## Результат

Создано приложение для управления списком задач с использованием DOM, обработчиков событий, модулей JavaScript и динамического обновления интерфейса.
